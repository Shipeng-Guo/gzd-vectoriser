# SVG component explosion and reassembly animation

Use to demonstrate an existing vector drawing's actual groups, members that move together, and occluded underlays. Produce an automatic out-and-back GIF suitable for embedding in other webpages. Unlike a wipe between two static images, each frame is generated by transforming SVG objects.

## Production and validation

1. Locate the actual SVG from the delivery report and record its hash. Inspect the DOM and candidate groups, choosing objects that demonstrate editing structure. A movable unit should contain all shapes, details, and names expected to move with it; do not quietly add unrelated labels for visual appeal.
2. Move existing `<g>` elements in a rendering copy. First generate the exploded endpoints and check that objects stay within bounds and do not obscure one another. If the full composition is crowded, use local scenes and `retain` to hide unrelated layers temporarily, identifying the scene as a "partial layer view" in its title. Preserve group ancestors, order, transforms, and actual underlays. Do not use screenshot crops or temporary paint to fake underlay completeness.
3. Inspect both the displaced and original positions. Use `probe_occlusion.mjs` to check underlays in specified regions, supplementing with whole-object checks from the structure-checking workflow as needed. If content is missing, repair the SVG itself and repeat acceptance; do not patch holes only in animation frames. Exporting an animation of an already accepted artifact does not require rerunning the entire source-image reconstruction workflow.
4. Build the sequence "hold assembled → ease out → hold with underlay exposed → return → hold assembled". Specify displacements in root SVG coordinates; the tool converts nested scaling and rotation. A presentation may contain multiple scenes, ending with the complete composition.
5. Inspect the actual encoded GIF, including each segment's endpoints and playback. The script checks displacement, stationary underlays, bounds, return-to-origin images, and unchanged source files; the encoder decodes frames to check color frames and timing. Structural checks cover only declared objects. The animation does not replace editability acceptance of the whole drawing.

## General interface

Dependencies: Node + Playwright + sharp + Chromium; Python + Pillow. Set an available `NODE_PATH` and specify the browser with `--browser`. Output must use a new directory. Keep project IDs, displacements, and scene configurations in the project, not in the shared skill.

```sh
node scripts/render_group_motion.mjs --svg final.svg --config motion.json \
  --out keyframes --browser /path/to/chrome --keyframes-only
# Inspect endpoints and confirm composition and underlays before rendering the full motion.
node scripts/render_group_motion.mjs --svg final.svg --config motion.json \
  --out rendered --browser /path/to/chrome
python scripts/encode_motion_gif.py --manifest rendered/frames.json --out animation
# Optional: save a smaller web version from the same frames.
python scripts/encode_motion_gif.py --manifest rendered/frames.json --out web --width 960 --frame-step 2
```

Example `motion.json` using anonymous objects:

```json
{
  "canvas": [1200, 1000],
  "fps": 20,
  "header_height": 104,
  "footer_height": 50,
  "scenes": [{
    "title": "Component displacement and return",
    "caption": "The foreground moves as a group while the underlay stays in place",
    "viewBox": [0, 0, 800, 600],
    "moves": [{"id": "foreground-unit", "delta": [0, -80]}],
    "watch": ["complete-base"],
    "travel_seconds": 1.6,
    "hold_seconds": 2.2,
    "rest_seconds": 1.0
  }]
}
```

- `delta` uses root SVG coordinate units. Preserve each object's existing `transform`; do not move an ancestor and descendant simultaneously. Select their common parent to move them as a whole, or select sibling groups to separate them.
- Radial explosion: `{"childrenOf":"layer-id","radial":{"center":[400,300],"distance":80}}` selects all direct child `<g>` elements of that layer; each must have a unique ID.
- `watch` must include at least one genuinely stationary object per scene. It cannot be a moving group or an ancestor or descendant of one.
- `retain` is an optional array of IDs for partial layer isolation. Preserve these objects, their descendants, and necessary ancestors in full while temporarily hiding other drawing branches. Restore visibility after each scene.
- The encoder's `--frame-step 2` samples motion frames to reduce file size while retaining all endpoints and total duration. Smaller dimensions do not necessarily yield a smaller file; compare actual file sizes before delivery.
- `labels` overrides the footer stage text for `assembled / moving / exploded / returning / returned`, globally or per scene. Titles, captions, and stage labels belong to the presentation interface and are not written into the SVG.
- Currently only group translation in static, self-contained SVGs is supported. Scripts, SVG animations, and external resources are not executed. Inspect actual keyframes for complex filters, existing clipping, and occlusion.

Rendering outputs: a copy of the source SVG, configuration, PNG frames, and `frames.json` (source hash, group membership, displacement, stationary-underlay checks, clipping, and exact-return evidence). Encoding outputs: `exploded.gif`, `index.html`, a decoded endpoint montage in `check.png`, and `animation.json`. All frames share a palette with explicit pure-white preservation to avoid background color changes and palette flicker.

Tool regression:

```sh
python scripts/test_group_motion.py --node /path/to/node --browser /path/to/chrome
```

Synthetic tests cover displacement in root coordinates under nested rotation and scaling, labels moving with their groups, stationary underlays, exact return, GIF decoding and pure white, plus rejection of simultaneous ancestor/descendant movement and out-of-frame objects.
